# v0.2.2 验证记录

日期：2026-10-16。机器：Apple M2 Pro，32 GB 统一内存，macOS 15.6。

## 核心检查

Release 构建成功，`PaperCoreChecks` 共 29 项检查通过。

新增检查覆盖：

- 长达 200 页的来源只请求页码 0、1、2；开头空白不向后补读，单页文件仅读一页。
- 摘要固定包含研究动机、核心方法、实验结果，未报告结果的文本可明确保存。
- 没有本版摘要时不创建向量单元；有摘要时只有一个单元，输入与中文摘要的规范化正文完全一致。
- 修改个人笔记、论文标题或分类不改变向量；更改摘要则使旧向量失效。笔记仍可关键词搜索。
- Schema 3 升级到 4 前生成一致性备份；旧实验缓存被清理，论文、阅读位置、个人笔记和词库保留，备份中仍可恢复旧记录。
- Markdown 不再包含自动实验台账。

旧版数据结构的历史回归检查继续保留；当前 app 不调用实验抽取流程。

## 真实模型与速度

使用本地 22 页 OmniVoice 论文（arXiv:2604.00688v3），与 app 共用 `PaperSummarySource.pdf` 和 `ResearchClient.summarizeOpening`。隔离工具的实测结果：

| 项目 | 结果 |
| --- | --- |
| 实际读取范围 | 仅第 1、2、3 页，10,177 字符 |
| 大模型 | Qwen3.6 27B Q4_K_M，关闭思考，16K 上下文 |
| 摘要模型调用次数 | 1 |
| 摘要耗时 | 110.81 秒，包含 PDF 加载和模型首次加载 |
| 摘要向量建立 | 1.82 秒，1 个向量，1024 维 |
| 自动实验记录 | 0 |

这是单篇实测，不是普遍耗时承诺。初测后进一步收紧了提示词：避免扩写采样等实现细节，缺少效果数值时明确注明，实验结果部分不罗列训练统计。模型摘要仍可能误解原文，需要人工阅读核对。

## 检索诊断

语料：一份真实的前三页中文摘要，另一篇没有摘要的真实论文。向量数为 1，没有为未整理论文创建标题替代向量；本项不读取任何 PDF。

| 查询 | 结果 |
| --- | --- |
| 扩散语言模型支持多语言零样本语音合成 | 命中 OmniVoice |
| diffusion language model for zero-shot multilingual speech synthesis | 命中 OmniVoice |
| 量子纠错表面码需要多少物理量子比特？ | 无命中 |
| CRISPR 基因编辑如何作用于干细胞？ | 无命中 |

四项均符合预期；两项相关查询的本地重排分数约 0.9996、0.9979。小样本检查只确认当前路径可用，不代表大规模论文库的准确率。原文后半部分的独有内容不会进入摘要向量。

原始诊断输出位于开发机被 Git 忽略的 `.test-output/v022-summary/` 与 `.test-output/v022-retrieval/`；未复制到用户数据库。
