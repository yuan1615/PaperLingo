# v0.2.1 验证记录

环境：Apple M2 Pro、32 GB 统一内存、macOS 15.6。验证日期：2026-10-15 至 2026-10-16。以下是功能与小样本诊断，不是通用学术摘要准确率或大规模检索评测。

## 结构化实验与速度

使用同一份 22 页 OmniVoice 论文的本地 PDF，先检查 PDFKit 提取文字，并渲染第 8 页对照真实表格。未修改原论文文件。

| 项目 | 结果 |
| --- | --- |
| 旧版完整整理 | 续跑后 3155.99 秒，约 52 分 36 秒；之前还有一次约 207 秒的运行 |
| 新版无提取缓存运行 | 532.16 秒，约 8 分 52 秒 |
| 其中实验提取 | 476.60 秒 |
| 其中概览生成 | 55.23 秒 |
| 大模型调用 | 2 次：一次结构化提取、一次概览；旧版为 13 组提取和 6 次合并 |
| 实验表 | 10 项识别、10 项完成字段提取 |
| 证据覆盖 | 保存 84 份原文块，实际提供 30 份重点证据；没有宣称逐段分析全部正文 |

这里的“无缓存”指没有 PaperLingo 结构化提取缓存；时间包括该次模型加载与生成，不包含后续向量索引。机器负载、表格复杂度、证据量都会影响实际耗时，不能承诺所有论文都在 9 分钟内完成。提速来自减少重复生成及逐层合并，没有更换 27B 模型。

随后复用同一份模型输出，改进数值符号、复合条件和来源行定位的本地校验，再生成概览，耗时 64.91 秒。它是缓存重校验，不能与冷整理混为一谈。最终保留 20 条代表性数值，完整 10 张表及其他数值仍在原文证据中；13 个字段或定位需要进一步人工核对。字段存在于原文，不代表模型已正确理解表头或统计意义。

最后补充了短原文片段保留与孤立表编号识别：最终规划保留 85 份原文块，其中单独的 `Table 11.` 仍作为文字保留，不再误计为实验。实验表仍为 10 项、数据资料为 2 段；提供模型的实验计划仍为一组、21,437 字符，与上述冷整理输入一致。

原始诊断报告：[冷整理](verification/v021-analysis-cold.json)、[缓存重校验](verification/v021-analysis-reground.json)。报告不包含用户论文路径或个人笔记。

## 每篇论文一个索引

按用户最终确认的设计，检索单元是论文概览卡：AI 概览为主，补充标题、分类、标签和个人笔记，最多 3600 字符。每篇只有一个向量，页数不会增加向量数量。没有 AI 概览时使用明确标注的标题/手工资料降级。原文、实验表和参考文献不参与默认检索索引。

诊断素材为两篇本地真实语音论文，其中一篇使用已生成的真实 AI 概览，另一篇验证标题降级；另加两份明确标注的合成手工资料与一条合成笔记。它们只写入隔离数据库。

| 项目 | 结果 |
| --- | --- |
| 当前论文索引 | 4 篇、4 个向量 |
| 相同素材的旧正文索引 | 58 个向量 |
| 向量 JSON 数据体积 | 50,895 字节，旧版 737,831 字节，减少约 93% |
| 新建四篇索引 | 1.39 秒 |
| 8 个查询 | 8 个符合预期；6 个相关查询各返回预期论文，2 个无关查询返回空结果 |
| 查询耗时 | 首次加载约 7.8 秒；后续相关查询约 0.5–1.1 秒，无关查询约 0.02 秒 |

体积只比较序列化向量，不是整个数据库或模型体积；保留的 PDF 和证据仍占空间。全文细节若未进入概览或笔记，可能无法检索到，这是本轮主动选择的论文级检索范围。

最终排序使用关键词/向量融合、本机重排、最低相关性及相对最佳候选的分差过滤；显式小数指标还须出现在索引卡。重排分数不是校准概率，阈值尚需更多真实查询检验。见 [最终检索报告](verification/v021-paper-retrieval.json)。

## 回归与界面

- 26 项 Swift 核心检查通过：原文结构、实验字段与数值验证、截断 JSON 恢复、长文证据预算、记录/核对/缓存持久化、每篇一个索引、增量失效、无关候选过滤及旧库升级备份。
- 26 项 Python 检查通过：既有语音/下载协议，以及本地重排的输入边界、来源限制、失败处理与逐文档分数。
- 原生隔离应用验证了实验卡片、完整证据展开、核对状态、从证据创建笔记、笔记保存、取消后保留概览和笔记、回到 PDF 第 8 页及 Markdown 导出。
- Markdown 实际导出包含结构化实验、完整证据和人工核对状态；JSON 导出版本 3 包含证据台账与核对状态。

## 离线运行

自包含 app 使用自己的 Python 3.11.17 / PyTorch 2.8.0；17 个权重文件 SHA-256 校验、内置依赖导入和 MPS 检查通过。最终包的真实翻译生成中文，长语音首段约 11.7 秒返回、第二段约 23 秒返回；本地重排将相关材料排在无关材料之前。该语音样本只验证分段协议，不代表所有句子的延迟。见 [离线包报告](verification/v021-portable.json)。

正式安装副本严格签名校验通过，并已从 `/Applications/PaperLingo.app` 启动。新安装期间曾在 macOS 加载器阶段等待较久，随后自行完成启动；该首次等待的系统原因尚未完全确定。构建和打包已改用新文件原子替换主程序，签名字节保持不变，以减少原地覆写风险，没有关闭系统安全检查。最终版本通过两次常规退出再打开，界面观察分别为 916 ms 和 1155 ms，不含工具网络/审批等待，也不代表首次安装耗时。见 [启动检查](verification/v021-launch.json)。旧 v0.2.0 app 与升级前数据库/偏好均已备份保留。

原库的两篇论文、五个词条、五次查询、四次复习及阅读位置均保留。schema 3 中两篇各有一个 1024 维向量，旧正文向量已清空，原文证据保留，提醒时间仍为用户原有的北京时间 19:30。两篇当前均没有 AI 概览，暂用标题/手工资料；用户点击「用本地模型整理论文」后，概览自动进入同一索引。没有用测试笔记或测试概览填充用户数据库。见 [安装检查](verification/v021-installed.json)。

大模型完成/取消后卸载，语音和重排服务恢复；测试只停止自己启动的进程。固定 Qwen3 Reranker 快照、权重 SHA-256 和许可材料随包记录。默认仍是 ad-hoc 签名，未做 Apple Developer ID 公证。本轮未生成新 DMG，也未推送 GitHub 或改动 CI 权限。

扫描件 OCR、图片理解、复杂表格行列关系的自动验证和统计显著性判断不在本轮范围。用户仍须核对实验解释和模型生成的文字结论。
