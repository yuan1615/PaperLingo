# PaperLingo v0.4.0 · Mac 口语练习

在 Mac 上读完一段论文后，用户可以直接和英语教练谈论它，遇到难词就切换到生词练习。三种模式共用本次会话，研究库、生词和练习结果沿用同一台 Mac 的 SQLite 数据库。

## 从阅读进入对话

| 入口 | 教练使用的材料 | 一轮练习 |
| --- | --- | --- |
| 论文讨论 | 选择的论文摘要及其覆盖范围，或用户指定的原文摘录 | 先请用户用英语复述动机、方法或结果，再围绕用户的回答追问。缺少证据时请用户提供原句 |
| 生词练习 | 选择的词条、已有释义及所在原句 | 听懂原句，换个情境造句，再试着把难词用于描述自己的研究 |
| 自由对话 | 新开对话时由用户自己给出话题 | 支持插话、要求重说和中文提示。切换到其他模式时可以补充材料 |

用户主动开始后，应用向系统请求麦克风权限，以本机钥匙串内的个人项目密钥连接 OpenAI。界面持续显示会话状态，以及静音与结束按钮。模式切换不重建连接。已经发给教练的材料仍属于同一场对话，结束后再开始可清空上下文。退出练习页会停止拾音和连接。

## 声音和材料

Mac 使用 AVAudioEngine 采集麦克风音频，并逐块播放模型返回的语音。对话采用 OpenAI Realtime 和 `gpt-realtime-2.1-mini`，复用已有官方域名、鉴权与重定向策略。教练直接接收音频和返回音频。转写仅用于查看与复盘。用户插话时立即清理还未播放的声音，并按实际播放位置更新本次会话。[实时对话与中断](https://developers.openai.com/api/docs/guides/realtime-conversations) · [语音模型](https://developers.openai.com/api/docs/models/gpt-realtime-2.1-mini)

论文材料在发送前可预览。教练区分全文摘要和前三页摘要，只有原句记录有真实页码时才带页码。进入练习页只读取本地资料。实时语音按 OpenAI 用量计费，通话音频和本次转写默认不落盘。

## 练习结束

保留当前页面的对话转写供用户回看。可从自己的原话整理少量表达建议，修正听错的术语，自己选择保存哪条。表达包含原话、改进说法、简短理由和可选论文出处，可在口语练习页和关联论文中再次查看。生词熟悉度由用户主动评分，使用现有复习规则。保存一条表达与累计一次查词、推进「今日练习」是不同的操作。

## 开发与验收

1. 验证长连接握手、音频输入输出、同场切换模式、打断截断和断线收尾。用模拟传输检查发送内容和顺序。
2. 接入 Mac 麦克风、流式播放器和练习界面。验证进入页面、拒绝权限、会话中退出、设备切换与重试。
3. 用 v0.3.1 隔离样例库验证升级、表达保存与回看、用户评分及旧复习队列。
4. 构建可打开的 macOS App。分别记录模拟测试、真实 API、麦克风和扬声器实测结果。
