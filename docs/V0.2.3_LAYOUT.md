# v0.2.3：内容优先的研究库与就地选区操作

## 设计

研究库原有品牌横幅、标题说明、搜索、筛选、分类按钮、详情标题及操作行层层叠加，摘要进入可视区的位置过低。本轮把主要空间交还给论文内容：

- 顶部只保留一行搜索工具栏，筛选与排序按需弹出，批量整理收进导入菜单。
- 导航栏在研究库中不再重复列出论文；左侧论文列表与右侧内容各司其职。
- 选择论文后默认显示摘要，标题最多两行，常用操作只有读原文与更多。摘要、笔记和资料可直接切换。
- 分类建议、模型信息和检索摘录默认折叠。小窗口改为列表与详情切换，保留明确的返回入口。

阅读时不再要求来回移动到固定学习面板：

- PDF 或网页正文选词、选句，松开鼠标后约 120–180 毫秒显示选区操作；拖选期间不遮挡文字。
- 原生 `NSPopover` 锚定可见选区，提供翻译、朗读，以及慢速、原句、复制与笔记等更多操作。译文也在弹层中显示，长译文可在内部滚动。
- 弹层不参与正文布局；翻译、播放音频都不改变文档滚动位置。专注模式下同样可用。
- 滚动、调整窗口、点击其他位置或按 Esc 收起。选区消失或离开阅读空间时清理弹层；原有侧栏和键盘快捷键仍可使用。
- 翻译仍受 4,000 字符上限限制，朗读仍受 12,000 字符上限限制，使用既有本地模型和查询统计规则。

实现位于 `ResearchViews.swift`、`Readers.swift`、`SelectionPopover.swift`。数据库 schema 与模型保持不变。

## 手工验证

2026-10-16，在独立应用标识与独立数据目录中检查，避免将诊断词条写入用户学习库。诊断 PDF 为一页明确标注的界面测试资料；网页为本地测试快照，不作为学术论文。

- 研究库大窗口默认显示摘要；当前窗口中，VISTA 的研究动机、核心方法与实验结果均在首屏可见。
- 筛选和排序从工具栏弹出，Esc 可关闭；较窄窗口能切换到详情并返回列表。
- PDF 专注模式中双击单词、拖选完整句子均弹出操作；译文成功显示，点击朗读成功调用 OmniVoice。
- 翻译和播放前后，PDF 滚动条位置保持一致；Esc 收起弹层后仍处于专注模式，滚动可收起弹层。
- 网页选词与本地翻译成功，结果在选区弹层显示；没有依赖固定学习侧栏。
- 普通阅读模式下，学习侧栏同步更新选区和译文时，弹层仍稳定保留；不会因为普通视图刷新被误关闭。
- Release 构建成功，既有 29 项核心检查全部通过。界面测试词条仅存在于独立诊断库，没有写入用户词库。

这里记录的是具体手工场景，不能代替所有 PDF 版式、触控板手势及辅助功能的全面验证。
