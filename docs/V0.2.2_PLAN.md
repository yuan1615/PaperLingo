# v0.2.2：前三页中文摘要

本轮按用户最新要求收紧范围：不保留自动实验记录，只根据论文前三页整理摘要，再为每篇论文建立一个中文摘要向量。

## 整理流程

1. 用户主动点击「生成前三页摘要」。PDF 只调用第 1–3 个物理页面的文字提取；不足三页则读取已有页面。前三页空白时报告需要 OCR，绝不向后补读。网页仅使用正文开头最多 15,000 字符，并明确显示范围。
2. Qwen3.6 27B Q4 关闭思考模式，以一次请求、16K 上下文和固定 JSON 格式返回一句话回顾、研究动机、核心方法、实验结果、建议分类及标签。无需逐段抽取、实验表解析或二次汇总。
3. 实验结果只能依据开头内容中的本文报告。保留明确的数据集、指标与条件；只有定性报告时注明缺少数值，没有结果则明确说明。摘要中的作者主张不等于已经核验全文实验。
4. 完整响应通过结构检查后再保存。取消、网络错误、超长输入或输出截断不覆盖已有摘要。原论文、个人笔记、手工档案独立保存。
5. 卸载大模型，加载 Qwen3 Embedding 0.6B，为一句话回顾和三部分中文摘要生成唯一向量。分类标签、英文标题、原文和个人笔记不混入向量。

实际生效的提示词与规范集中在 [PaperSummary.swift](../Sources/PaperCore/PaperSummary.swift)；固定字段为 `oneLine / motivation / method / results / category / tags`，避免文档和程序各自维护一份 prompt。

## 检索与交互

- 论文详情只有「档案 / AI 摘要 / 笔记」三个页签，移除实验台账和核对状态。
- 关键词检索仍覆盖标题、文献资料、中文摘要和个人笔记。
- 语义检索只检索已有本版摘要的论文，以本地重排模型过滤弱相关结果。没有摘要的论文不生成标题替代向量。
- 索引的标识只由论文 ID 与中文摘要内容决定。修改笔记、改名或分类不触发向量重建。
- 「建立 / 更新检索索引」只读已保存摘要，不访问 PDF。打开研究库也不自动提取正文。
- 仅凭前三页和简短摘要，检索不到后文特有细节属于明确的范围限制。

## 数据升级

Schema 4 在任何清理前通过 SQLite 在线备份 API 生成一致性备份。随后在事务中清空旧实验台账、人工核对、全文证据缓存与旧向量。论文文件、阅读位置、词库、复习事件、手工资料和个人笔记保留；历史摘要保留但不参与新语义索引，需重新生成。

升级备份保留用于恢复旧版数据，不属于新功能的活动实验记录。JSON 导出版本为 4；JSON 和 Markdown 不再导出自动实验台账。

## 验证

核心检查覆盖前三页边界（含空白页、短文、长文）、三部分固定摘要、摘要唯一向量、笔记变动不重建向量，以及升级清理与学习数据保留。真实模型诊断使用隔离数据库，测量一次摘要调用和单个向量的实际耗时；不把少量样本的结果当作一般准确率或速度承诺。
