## 范围和边界

这轮 UI 操作使用独立 bundle identifier 和 `.test-output/v02-qa` 数据目录；测试笔记没有写入用户学习库。首次打开 v0.2 预览时，真实用户库已经执行一致备份并迁移到 v2；原论文、词库和提醒偏好保留。

原文摘录匹配只能证明摘录存在，不能证明 AI 解释、元信息或数值推论正确。扫描件 OCR、云同步和自动跨论文问答尚未实现。v0.1 既有离线包保留，本轮尚未生成 v0.2 完整离线镜像，也未启用或申请 GitHub workflow 权限。
