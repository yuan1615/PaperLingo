## 范围和边界

这轮 UI 操作使用独立 bundle identifier 和 `.test-output/v02-qa` 数据目录；测试笔记没有写入用户学习库。首次打开 v0.2 预览时，真实用户库已经执行一致备份并迁移到 v2；原论文、词库和提醒偏好保留。最终安装前另做一致性备份：5 篇论文、5 个词条、5 条查词日志、4 条复习事件；不把隔离测试数据迁入该库。旧安装 app 保留于 `dist/PaperLingo-0.1.0-installed-backup.bundle`，旧 v0.1 DMG 与分发目录均保留。

原文摘录匹配只能证明摘录存在，不能证明 AI 解释、元信息或数值推论正确。AI 仅分析文字层，未解读图片或图表。扫描件 OCR、云同步和自动跨论文问答尚未实现。v0.1 既有离线包保留，本轮尚未生成 v0.2 完整离线镜像，也未启用或申请 GitHub workflow 权限。

## 人工质量抽查

完整结果将英语、中文训练数据时长选入两条“实验与结论”，对主要 benchmark 的数值比较保留不足；部分解释超出了短摘录本身能直接证明的范围。引用文本匹配只确认文字存在，不验证完整解释的蕴含关系。当前自由分层合并存在细节压缩问题，不能替代精细实验对比；后续应优先保存数据集、指标、基线、数值及条件组成的实验记录，再生成最终回顾。
